# Sturdy Vanilla — site

Static pages for Sturdy Vanilla, served by GitHub Pages.

Deliberately minimal: a holding page plus the privacy policy and terms that
TikTok's developer audit requires. No cookies, no analytics, no external
fonts or scripts.

Hosted on `sturdyvanilla.github.io` — intentionally not attached to any domain.
Sturdy Vanilla stays separate from the other domains Joe owns, and a domain
will only be bought once the venture is making money.

- `index.html` — holding page
- `privacy.html` — privacy policy (covers the TikTok API integration)
- `terms.html` — terms of service
- `style.css` — one stylesheet, light/dark aware
