# Sturdy Vanilla, the site

One scroll-driven page for Sturdy Vanilla, served by GitHub Pages, plus the
privacy policy and terms that TikTok's developer audit requires and the
creator brief that creators are sent by link.

No cookies, no analytics, no third-party fonts or scripts. The typeface
(Fraunces, OFL) and the scroll engine are served from this repository.

Hosted on `sturdyvanilla.github.io`, deliberately not attached to a domain.
Sturdy Vanilla stays separate from the other domains Joe owns, and a domain
will only be bought once the venture is making money.

- `index.html`, `site.css`, `site.js`: the page. Built with scroll-craft;
  `scrollcraft.js` and `scrollcraft.css` are the engine and are never edited here.
- `privacy.html`, `terms.html`: the small print. Registered with TikTok, so
  these URLs must keep resolving. The page opens them in a dialog.
- `creators.html`: the creator brief (noindex, handed out by link).
- `style.css`: the stylesheet for the small-print pages.
- `assets/`: fonts, images, the short clips.
- `device-diag.html`: a phone diagnostic for the scrub clip (noindex).
